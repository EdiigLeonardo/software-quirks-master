# JavaScript Quirks

A collection of JavaScript quirks and browser inconsistencies, documented and demonstrated in a web application.

## Features

- **Interactive Demos**: Explore various JavaScript quirks with live examples.
- **Component Tagging**: Built with [Lovable](https://lovable.dev/) for component documentation.
- **Modern Stack**: Built with React, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (or [Bun](https://bun.sh/)) - This project uses npm.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd javascript-quirks
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3030](http://localhost:3030) in your browser to view the application.

### Build

Build the application for production:

```bash
npm run build
```

### Run Tests

Run the test suite:

```bash
npm test
```
